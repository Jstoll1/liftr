# Chest image library

8 AI-generated exercise illustrations matching the Liftr leg-day collection.

Use the JPEGs in `images/chest/` for the app. Original PNGs are in `assets/images/chest/`. Exact prompts are in [prompts.json](../../assets/images/chest/prompts.json); paths, equipment and review status are in `assets/manifest.json`. All images need qualified trainer review before use as technique guidance.
