# Character animation sources

This folder stores editable source artwork for character animations.

## Vega

- `vega-spritesheet.png`: original transparent eight-frame sprite sheet.
- App-ready animation: `../../../images/characters/vega-scurry.gif`
- Playback: 90 ms per frame, loops continuously while visible.
- UI use: Jessica's welcome screen animates the GIF across the top of the viewport.

Keep source sheets here and export optimized runtime files to `images/characters/` so the app can reference them directly.
