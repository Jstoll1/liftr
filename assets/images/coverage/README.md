# Full exercise coverage expansion

This collection contains 64 source PNGs generated on September 1, 2026 to close every remaining exercise-image gap reported by `scripts/audit-exercise-images.js`.

App-ready 768-pixel JPEGs are distributed among the existing `images/arms/`, `images/back/`, `images/chest/`, `images/core/`, `images/legs/`, and `images/shoulders/` folders. Fifteen additional exercise names reuse existing app-ready images where the workout instructions confirmed an equivalent movement.

Every generated image uses a square photorealistic fitness-instruction style, a dark navy studio, blue and magenta rim lighting, modest black athletic clothing, no text, and clear visibility of the athlete and equipment. Each exercise prompt then specified its named movement, required equipment, body position, and whether one or two athletes were needed.

All exercise imagery remains pending qualified trainer review before use as authoritative technique guidance.
