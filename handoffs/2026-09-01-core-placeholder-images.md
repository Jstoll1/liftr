# Core placeholder image handoff

Six exercise images replace basketball fallbacks in Jessica's partner workout:

- Forearm Plank
- Dead Bug
- Elbow-to-Opposite-Knee
- Side Plank
- Bird Dog
- Hip-Flexor Stretch + Overhead Reach

The interface needs no code changes. Its existing candidate loader finds the app-ready JPEGs in `images/core/` using exercise-name slugs. Source PNGs and manifest records are under `assets/`.

All images were generated with the built-in image-generation tool and remain pending qualified trainer review for exercise technique.
